# Riverside Clinic Scheduling — Synthetic Demo

This training example contains no patient records or real clinic data.

The clinic scheduling desk coordinates appointment reminders and referral imports. Tara owns the scheduling workflow. The workflow depends on a reliable referral import from the lab interface. Some referral rows are still manually reconciled. Who owns after-hours exceptions? Duplicate reminders are a risk if an import is replayed. The next step is to confirm a safe handoff for the referral queue.
