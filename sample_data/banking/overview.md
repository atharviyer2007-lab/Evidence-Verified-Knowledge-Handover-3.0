# Sandbox Ledger Reconciliation — Synthetic Demo

This training example uses no real customer names, accounts, balances, or payment records.

The sandbox team reconciles a synthetic settlement file against a sample ledger. Mina owns the daily reconciliation. Month-end review depends on the settlement-file mapping. Several unmatched sample rows are still awaiting classification. Who approves month-end exceptions? Replaying the same settlement file could duplicate ledger entries, so the replay check is a key risk. The handover should preserve the review steps and escalation owner.
